# Reporting a vulnerability

Open the affected repository’s **Security** tab and select **Report a vulnerability** if it is available. Include the affected version, potential impact, and minimal reproduction steps with sensitive details removed.

If private reporting is unavailable, use a private contact channel you already have for the maintainer. If you have no private contact, open an issue asking for a private reporting channel without describing the vulnerability. Keep vulnerability details and credentials out of public issues and pull requests. If you own an exposed credential, revoke or rotate it promptly. Otherwise, notify the owner privately.
